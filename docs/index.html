About this network

Each line represents a unique, undirected airport pair found in the supplied route data. Airport degree counts distinct neighboring airports. The connection checker searches this graph one route layer at a time, so its iteration count is also the fewest flights when a path exists. The displayed network contains the selected U.S. and territory airports that have at least one domestic route; airports with no route are counted separately.
